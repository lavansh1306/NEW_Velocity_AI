# 🚀 Velocity AI - Comprehensive Project Documentation

## Executive Summary

**Velocity AI** is a full-stack workforce intelligence platform that transforms raw project events from multiple sources (Jira, HubSpot, Microsoft 365) into actionable CFO-ready insights. It tracks productivity gains from AI tools, reallocates freed capacity to high-impact initiatives, and proves ROI through causal attribution.

**Key Value Proposition:** Convert efficiency gains into measurable business outcomes with real-time dashboards, automation coverage metrics, cost savings analysis, and capacity forecasting.

---

## 📊 Project Overview

### Core Problem Solved
Organizations struggle to:
- Quantify productivity gains from AI/automation tools
- Allocate freed-up workforce capacity strategically
- Prove ROI of automation investments to executives
- Connect tool usage to actual business outcomes

### Solution Provided
A unified platform that:
1. **Ingests** data from 6+ platforms via APIs and CSV
2. **Normalizes** platform-specific events into canonical format
3. **Calculates** metrics (automation coverage, hours saved, cost impact)
4. **Visualizes** insights through role-specific dashboards
5. **Recommends** capacity redeployment strategies

## 🔌 Core Features & Functionality

### 1. **Multi-Platform Data Integration**

#### Jira Integration (Multi-Tenant SaaS)
- **Authentication:** OAuth 2.0 with PKCE (Proof Key Code Exchange)
- **Features:**
  - Real-time issue fetching from multiple Jira instances
  - Multi-site support (users can access all their Jira Cloud sites)
  - Automatic token refresh
  - Session-based state management
- **API Endpoints:**
  - `GET /api/jira/auth/connect` - Start OAuth flow
  - `GET /api/jira/auth/callback` - OAuth callback handler
  - `POST /api/jira/auth/disconnect` - Disconnect account
  - `GET /api/jira/auth/status` - Check connection status
  - `GET /api/jira/issues?projectKey=PROJ` - Fetch issues
  - `GET /api/jira/projects` - List accessible projects
- **Files:** src/api/jira/auth.ts, src/api/jira/routes.ts

#### HubSpot Integration
- **Authentication:** OAuth 2.0 flow with secure session storage
- **Features:**
  - Deals pipeline management

  - `GET /api/hubspot/deals` - Fetch deals

### 2. **Data Normalization Pipeline**

**Purpose:** Transform platform-specific events into a canonical format for unified analytics.

**Canonical NormalizedEvent Model:**
```
{
  eventId: string,              // Unique identifier
  timestamp: string,            // ISO 8601 UTC format
  app: string,                  // "jira"|"asana"|"hubspot"|"zapier"|"m365"
  actionType: string,           // "automation"|"manual"
  units: number,                // Count of items (default 1)
  avgManualMinutes: number,     // Estimated manual time per unit
  projectId: string,            // Join key for aggregation
  payload: object               // Original platform data
}
```

**Normalizers Location:** src/lib/normalizers/
- jira.ts - Normalize Jira issues
- asana.ts - Normalize Asana tasks
- hubspot.ts - Normalize HubSpot deals/contacts
- microsoft365.ts - Normalize M365 meetings
- zapier.ts - Normalize Zapier runs

**Data Flow:**
Raw CSV/API Data → Normalizer → NormalizedEvent
                                      ↓
                            Metrics Calculation
                                      ↓
                            JSON Storage or DB
                                      ↓
                            loadMetrics() Function
                                      ↓
                            UI Charts & Dashboards

### 3. **Metrics & Analytics Engine**

**Core Metrics Calculated:**

#### Automation Coverage %
= (# Automated Events / Total Events) × 100
Represents percentage of work handled by automation vs. manual effort.

#### Human-Hours Saved
= Σ(units × avgManualMinutes / 60) for automated events
Estimated hours freed up by automation per project/week/integration.

#### Cost Impact
= Hours Saved × Hourly Rate USD
Financial impact of automation in dollars. Configurable hourly rate (default: $100/hr).

#### Capacity Forecasting
= Current Hours Freed + Projected Savings × Forecast Weeks
Predict future capacity based on automation trends.

#### Redeployment Recommendations
AI-driven suggestions to allocate freed capacity to:
- High-impact projects
- Strategic initiatives
- Revenue-generating work
- Customer-facing activities

**Metrics Calculation File:** src/lib/metrics.ts

**Data Service:** src/lib/dataService.ts
- loadMetrics(projectId) - Load calculated metrics for a project
- loadProjects() - Load all projects with metadata
- loadCommitsByProject() - Git commits per project
- loadAsanaTasksByProject() - Asana tasks per project
- loadJiraIssuesByProject() - Jira issues per project
- loadHubSpotEventsByProject() - HubSpot events per project
- loadM365ActivitiesByProject() - Microsoft 365 activities per project
- loadZapierWorkflowsByProject() - Zapier automation runs

## 🔐 Authentication & Security

### OAuth 2.0 Implementation

#### PKCE Flow (Proof Key Code Exchange)
- **Why:** Prevents authorization code interception
- **Implementation:** Jira, HubSpot, Microsoft 365
- **Steps:**
  1. Generate code_verifier (random string)
  2. Create code_challenge (SHA256 hash)
  3. Redirect to platform with code_challenge
  4. Platform returns authorization code
  5. Exchange code + code_verifier for tokens

#### Session Management
- **Library:** express-session
- **Storage:** In-memory (configurable to DB)
- **Security:**
  - Secure cookies (HTTPOnly, Secure flags)
  - CSRF token validation
  - Session expiry
  - Multi-tenant isolation

#### Token Management
- **Automatic Refresh:** Tokens refreshed before expiry
- **Secure Storage:** Session-based (not localStorage)
- **Revocation:** User can disconnect anytime

### Security Features
- ✅ PKCE for OAuth flows
- ✅ HTTPOnly cookies for session tokens
- ✅ CORS configured for production domains
- ✅ Input validation with Zod schemas
- ✅ Environment variables for secrets
- ✅ No credentials in code
- ✅ Session-based state management
- ✅ Multi-tenant data isolation

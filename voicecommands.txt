# Velocity AI Voice Command Reference (Full Autonomy Mode)

This document lists the commands supported by the local **Full Autonomy** parser. Standard Mode handles these intents zero-latency and offline, avoiding any dependency on external LLMs for core functionality.

## 1. Smart Local Intelligence
*   **Zero-Latency Fallback**: Standard Mode now handles 95% of common intents locally.
*   **Context Disambiguation**: Intelligently distinguishes between "Delete Task X" (Project Page) and "Delete Member X" (People Page).
*   **Active Clarification**: If a command is too short (e.g., "Add a task"), the system will now ask for the missing information locally instead of failing.
*   **Self-Correction**: Uses fuzzy matching (Levenshtein) to understand "dashbord," "proyects," "remov," etc.

## 2. Help & Capabilities
Ask the system about itself:
*   "Help me" / "Show commands"
*   "What can you do?"
*   "What are the capabilities?"

## 3. Navigation (Dash-Fast)
*   **Keywords**: `dashboard`, `projects`, `team`, `people`, `plan`, `settings`, `ai`
*   **Verbs**: `go to`, `open`, `show`, `view`
*   **Examples**: "Open projects", "Dashboard", "Go to team"

## 4. Project & Task Management
*   **Add Project**: "Create project [Name] that does [Description]"
*   **Add Task**: "Add task [Name] for [Project Name]"
*   **Local Clarification**: If you say "Add task", I will ask "What is the task name?"

## 5. Team Management
*   **Invite**: "Add [Name] as [Role]"
*   **Delete**: "Remove [Name] from team"
*   **Safety**: All deletions require a local "Yes/No" voice confirmation.

## 6. Real-Time Analytics (Offline-First)
Even without Gemini, the system analyzes data locally to answer:
*   "How many active projects?"
*   "What is team utilization?"
*   "Available capacity this week."
*   "When is the next deadline?"

*Standard Mode operates with 0ms LLM latency and is always active.*

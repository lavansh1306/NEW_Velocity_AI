## 🎯 What is Velocity AI?

**Velocity AI** is an enterprise-grade **SaaS productivity analytics platform** that consolidates data from multiple business tools into a single, intelligent dashboard. We transform fragmented productivity data into actionable insights using machine learning, helping organizations optimize resource allocation, predict project outcomes, and maximize ROI.

### **Our Mission**

Empower enterprises to make data-driven decisions by providing real-time visibility into project health, team capacity, sales pipeline, and productivity metrics across all major business platforms.

### **Data Flow**

#### 1. OAuth Authentication Flow
```
User clicks "Connect" 
  → Frontend redirects to OAuth provider 
  → User authorizes application 
  → Provider redirects to callback endpoint 
  → Server exchanges authorization code for access token 
  → Token encrypted and stored in session (Redis/in-memory) 
  → Frontend receives authentication success status
```

#### 2. Data Fetching Flow
```
Component mounts 
  → useQuery hook triggers API call 
  → HTTP request sent to Express server 
  → Server validates session & OAuth token 
  → Server fetches data from external API 
  → Data transformed & normalized 
  → JSON response sent to frontend 
  → React Query caches data & updates UI
```

#### 3. Multi-Tenant Session Management
```
Express session stores:
  ├── OAuth access tokens (encrypted)
  ├── Refresh tokens (for automatic renewal)
  ├── Cloud IDs / Portal IDs (multi-tenant routing)
  └── User context (active site, preferences)

Session Persistence:
  ├── Development: Memory store (MemoryStore)
  └── Production: Redis (connect-redis)
```

## 🚀 Getting Started

### **Prerequisites**

- **Node.js 18+** ([Download](https://nodejs.org/))
- **npm** (comes with Node.js)
- **Redis** (optional, for production session management)

### **Quick Installation**

```bash
# Clone the repository
git clone https://github.com/velocityai588-tech/NEW_Velocity_AI.git
cd NEW_Velocity_AI

# Install dependencies
npm install

# Copy environment template
cp .env.example .env

# Edit .env with your credentials (see Environment Setup section)
```

### **Environment Setup**

Create a `.env` file in the root directory with the following configuration:

```bash
# ==============================================
# JIRA CONFIGURATION
# ==============================================

# Multi-tenant Jira OAuth 2.0 (Recommended)
# Create OAuth app: https://developer.atlassian.com/console/myapps/
JIRA_OAUTH_CLIENT_ID=your-atlassian-oauth-client-id
JIRA_OAUTH_CLIENT_SECRET=your-atlassian-oauth-secret
JIRA_OAUTH_REDIRECT_URI_LOCAL=http://localhost:4000/api/jira/auth/callback
JIRA_OAUTH_REDIRECT_URI_PROD=https://yourdomain.com/api/jira/auth/callback

# ==============================================
# HUBSPOT CONFIGURATION
# ==============================================
HUBSPOT_CLIENT_ID=your-hubspot-client-id
HUBSPOT_CLIENT_SECRET=your-hubspot-client-secret
HUBSPOT_REDIRECT_URI=http://localhost:4000/oauth/hubspot/callback

# ==============================================
# MICROSOFT 365 CONFIGURATION
# ==============================================
# Create app: https://portal.azure.com/#blade/Microsoft_AAD_RegisteredApps
MICROSOFT_CLIENT_ID=your-azure-app-id
MICROSOFT_CLIENT_SECRET=your-azure-client-secret
MICROSOFT_REDIRECT_URI=http://localhost:4000/auth/callback

# ==============================================
# ASANA CONFIGURATION
# ==============================================
ASANA_TOKEN=your-personal-access-token
ASANA_PROJECT_ID=default-project-id

# ==============================================
# SESSION & SECURITY
# ==============================================
# Generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
SESSION_SECRET=your-secure-random-session-secret-minimum-32-characters

# ==============================================
# SERVER CONFIGURATION
# ==============================================
API_PORT=4000
NODE_ENV=development
FRONTEND_URL=http://localhost:5173

# ==============================================
# SUPABASE (OPTIONAL)
# ==============================================
SUPABASE_URL=your-supabase-project-url
SUPABASE_ANON_KEY=your-supabase-anon-key
```

### **OAuth Application Setup**

#### **Jira OAuth**
1. Go to [Atlassian Developer Console](https://developer.atlassian.com/console/myapps/)
2. Create new app → OAuth 2.0 integration
3. Add callback URL: `http://localhost:4000/api/jira/auth/callback`
4. Permissions: `read:jira-work`, `read:jira-user`, `offline_access`
5. Copy Client ID and Secret to `.env`

#### **HubSpot OAuth**
1. Go to [HubSpot App Settings](https://app.hubspot.com/developer/)
2. Create new app → Auth tab
3. Redirect URL: `http://localhost:4000/oauth/hubspot/callback`
4. Scopes: `crm.objects.contacts.read`, `crm.objects.deals.read`, `crm.objects.companies.read`
5. Copy Client ID and Secret to `.env`

#### **Microsoft 365 OAuth**
1. Go to [Azure Portal](https://portal.azure.com/#blade/Microsoft_AAD_RegisteredApps)
2. Register new application
3. Redirect URI: `http://localhost:4000/auth/callback` (Web)
4. API Permissions: `Calendars.Read`, `Mail.Read`, `Chat.Read`, `User.Read`
5. Create client secret → Copy to `.env`

#### **Asana Token**
1. Go to [Asana Developer Console](https://app.asana.com/0/developer-console)
2. Create Personal Access Token
3. Copy token to `.env`

### **Running the Application**

```bash
# Start backend server (Port 4000)
npm run api

# In a new terminal, start frontend (Port 5173)
npm run dev

# Open browser to http://localhost:5173
```

### **Building for Production**

```bash
# Build frontend assets
npm run build

# The dist/ folder will contain production files

# Deploy backend + dist/ to your hosting platform
```
